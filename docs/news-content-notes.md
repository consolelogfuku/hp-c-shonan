# お知らせ記事データ

`src/lib/news.ts` はCMSへの初期取り込みデータとして使用。
現在、トップページ・一覧・詳細はCloudflare D1に保存された公開中の記事を表示する。
初回は現行一覧の11件を取り込み、1ページ10件で表示する。既存の `.html` URLを維持。
本文は2026-09-09に現行サイトを確認して作成した要約であり、原文の全文移行ではない。
各記事の `sourceUrl` が確認元。管理画面の起動と保存方法は [cms.md](cms.md) を参照。

## 現行サイトの記載差異

- `yabata2652.html`：見出しは石川矢畑NO6の成約告知だが、本文は岡田貸家についての内容。無関係な本文を転記せず、一覧見出しの成約告知だけを要約した。
- `2512parking-copy-copy.html`：一覧の日付は2026-03-29、本文は2026-04-10時点の空き状況。一覧日付を維持し、本文に情報の基準日を明記した。
- `sum718vac.html`：本文冒頭の日付に「2027月7月18日」とあるが、一覧は2025-07-18、休業期間も2025年。一覧日付を採用した。
- `hagi73lent.html`：一覧は2025-07-03、本文冒頭は2025-07-18。一覧日付を維持した。
- `samoka3581rent.html`：募集告知の後に募集終了の記事があるため、終了した旨を追記した。
