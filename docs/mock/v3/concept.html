住み心地を決めるのは、
予算より良いプランニング

家づくりのQ&A

建築費用はどのくらいかかりますか？

コミュニティ湘南独自の標準仕様があります。また、当社社長がお客様に合ったローンの見積もり、プランを導き出しますので、お気軽にご相談ください。標準仕様以外でも、ご希望のものはご満足頂けるよう丁寧に対応させていただきます。

建築相談はお金がかかりますか？

建築相談にはお金はかかりません。参考プランを作成しますので、どの程度のボリューム、プランができるかをご判断いただけると思います。

建築期間はどのくらいですか？

基本プランが決まってから地盤調査を行い、必要な場合は地盤改良工事を行います。その後、建築確認をとり、着工するまで概ね1か月（耐震等級3を取得する場合はさらに1か月）。その後、工期は4〜5か月程度かかります。

完成後もメンテナンスやリフォームをしてもらえますか？

施主検査をしていただき引き渡しをいたしますが、住まわれてからお気づきになる点もあるかと思います。完成後も、責任をもって対応させて頂きます。

耐震はどうなっていますか？

耐震等級3は、耐震等級1で想定する地震の1.5倍の耐震強度があり、消防署や警察署など防災の拠点となる建物の耐震性に相当すると言われています。当社でも耐震等級3を取得した建物を多数施工しています。

建築相談は無料です。
