調査日: 2026-09-05

## 4. 現行の課題（リニューアルで解消したいこと）

- **モバイル対応が UA 振り分け**: PC 版は 1280px 固定でメディアクエリなし。タブレットや幅の広いスマホで中途半端な表示になる。
- **成約済み物件が前面に出ている**: トップの売買スライダー 30 件中 29 件が「ご成約済み」。販売中 1 件が埋もれている。
- **同一コンテンツの重複表示**: 施工事例 42 件が 2 回、賃貸 4 件が 3 回、トップに並ぶ。
- **「お客様の声」がナビに無い**: 信頼獲得の要となるコンテンツなのに、バナー画像とサイトマップからしか辿れない。
- **駐車場の空き状況が画像 + 手書きテキスト**: 更新のたびに画像を作り直す運用。構造化データにすれば一覧・バッジ表示が自動化できる。
- **色の使い方**: 赤（`#ff0000`）の強調が 36 箇所、黄の問い合わせボタン、緑の見出し、青のロゴ。アクセントが 4 色あり視線が散る。
- **旧ブラウザ対応の残骸**: html5shiv / respond.js（IE 8 対応）、Swiper 3.x、GA の旧 UA タグ。
- **OG 画像・description が空**: SNS シェア時のカードが機能していない。
- **写真の質は高い**: 施工事例の内観・外観写真は 1200〜1500px で撮影されており、そのまま素材として使える。

## 5. 保全すべきもの（SEO・運用）

- URL 構造（`/news/`、`/sale/{slug}.html` など）。移行時は同一パスを維持するか 301 リダイレクトを用意する。
- グローバルナビのラベル（新着情報 / 家創りのコンセプト / 売買物件 / 賃貸物件 / 施工事例 / 会社案内）。
- `<title>` に含まれる「茅ヶ崎 土地 注文住宅」というキーワード構成。
- お問い合わせフォームの項目（5 つのチェックボックスの選択肢を含む）。
- ヒーローの海の写真、建築家 吉田靖氏のコメント、感謝会の記述など、地元感と人柄を伝える文章の語調。

## 6. リニューアル案（このリポジトリの実装）

- スタック: Next.js 15（App Router）+ Tailwind CSS v4 + Motion + Phosphor Icons。フォントは しっぽり明朝 B1（見出し・本文）と Klee One（人の言葉）を next/font でセルフホスト。背景は塗り壁写真（public/nurikabe.png）、角丸なし、ライトテーマのみ。
- 制作フロー: `docs/mock/top.html` の HTML モックで合意してから Next.js に反映する。モックと Next.js は同じ構成・トークンで揃えている。
- デザインリード: 「茅ヶ崎の家族向け不動産・注文住宅会社のリニューアル。信頼感を最優先にした穏やかな海辺のトーンで、ブランドの海の青をただ 1 色のアクセントにする」。
- ダイヤル: DESIGN_VARIANCE 5 / MOTION_INTENSITY 5 / VISUAL_DENSITY 4（現行は 3 / 4 / 5 と読み取り、オーバーホール扱いで variance と motion を +2、密度は少し下げた）。
- 参考にした施工会社サイト（住友林業 / ダイワハウス / 一条工務店 / メルディア with one）に共通する「白ベース」「画面幅いっぱいの写真」「中央揃えの短いコピー」を採用。ヒーローは湘南の海の写真 3 枚をゆっくり切り替える全幅表示にした。
- 情報設計は維持しつつ、トップは「販売中の物件を 1 件だけ大きく」「施工事例は横スクロール」「お客様の声をナビに昇格」「駐車場の空き状況を構造化データからタイル表示」に再構成。
- 全コンテンツ（物件・施工事例・お客様の声・お知らせ・駐車場）は `src/lib/site.ts` に集約し、後段で管理画面（ヘッドレス CMS）に差し替えられる形にしている。施工事例の写真は現行サイトのものを仮参照している。
- 下層ページは第 2 フェーズ。現状は `/{section}/` にアクセスすると現行サイトの該当ページへ案内するプレースホルダーを表示する。
